# Code of Conduct

## Our Commitment

AllTick aims to provide a welcoming, respectful, and constructive environment for developers, contributors, and community members.

We welcome participation from people with different backgrounds, experience levels, and technical perspectives.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Communicate constructively.
- Provide useful technical feedback.
- Respect different viewpoints.
- Focus discussions on the project and its users.
- Help maintain a welcoming developer community.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks.
- Discriminatory or hateful conduct.
- Threats or intimidation.
- Publishing private or confidential information.
- Deliberately disrupting project discussions or contributions.
- Spam or unrelated promotional content.

## Project Discussions

GitHub Issues and Discussions should be used for constructive project-related communication.

Please provide relevant technical information when reporting bugs, asking questions, or suggesting improvements.

Do not publish API tokens, passwords, private keys, or other sensitive credentials.

## Enforcement

Project maintainers may take appropriate action when community participation violates these guidelines.

Actions may include removing inappropriate content, restricting participation, or other measures necessary to maintain a constructive project environment.

## Scope

This Code of Conduct applies to interactions within the AllTick GitHub project and its associated community spaces.
