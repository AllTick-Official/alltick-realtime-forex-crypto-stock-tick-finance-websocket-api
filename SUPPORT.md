# AllTick Support

## Getting Started

If you are new to AllTick, start with the official API documentation and the examples provided in this repository.

The documentation covers API access, authentication, market data, symbols, REST API usage, WebSocket API usage, and integration examples.

## API and Integration Questions

For questions about:

- REST API integration
- WebSocket integration
- Authentication
- Market data
- Symbols and instruments
- Tick data
- Order book data
- K-line data
- Historical data
- Programming language integration

please use GitHub Issues or GitHub Discussions.

## Bug Reports

If you believe you have found a bug, search existing GitHub Issues first.

When creating a new issue, provide enough technical information to reproduce the problem.

Do not publish API tokens, passwords, private credentials, or other sensitive information.

## Feature Requests

Feature requests and suggestions are welcome.

Please describe the requested capability, the affected market or data type, and the practical use case.

## Documentation Feedback

If you find inaccurate, outdated, incomplete, or unclear documentation, please report it through GitHub Issues or submit an improvement through a Pull Request.

## Community Discussions

GitHub Discussions can be used for:

- API usage questions
- Integration discussions
- Developer feedback
- General product questions
- Sharing implementation experiences

## Official Resources

AllTick's official website and API documentation are the primary sources for product and API information.

This GitHub repository provides additional developer documentation, examples, and integration resources.
