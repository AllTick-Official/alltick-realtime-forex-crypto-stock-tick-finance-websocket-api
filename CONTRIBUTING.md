# Contributing to AllTick

Thank you for your interest in contributing to AllTick.

AllTick provides financial market data APIs for developers, quantitative researchers, fintech applications, trading tools, and financial software.

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting API improvements
- Improving documentation
- Adding or improving code examples
- Sharing integration feedback
- Reporting missing market or symbol coverage
- Improving developer experience

## Reporting Bugs

Before reporting a bug, please check the existing GitHub Issues to avoid duplicate reports.

When reporting an API or data issue, include:

- API or WebSocket endpoint
- Request parameters or relevant configuration
- Symbol or market involved
- Expected behavior
- Actual behavior
- Error message or response
- Steps to reproduce the issue

Please do not include API tokens, passwords, private credentials, or other sensitive information.

## Feature Requests

For feature requests, please describe:

- The feature you would like to see
- The market or data type involved
- The reason it would be useful
- A practical use case or example

## Documentation Contributions

Documentation improvements are welcome, including:

- API usage examples
- REST API examples
- WebSocket examples
- Programming language examples
- Market and symbol documentation
- Error handling guidance
- Integration tutorials

## Pull Requests

For code or documentation changes:

1. Keep changes focused and easy to review.
2. Explain what was changed and why.
3. Update relevant documentation when necessary.
4. Include examples when they improve clarity.
5. Do not include API credentials or private information.

## Community

Questions, integration discussions, and general developer feedback are welcome through GitHub Issues and Discussions.

For official AllTick documentation and API information, please refer to the official AllTick website and documentation.
