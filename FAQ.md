# AllTick API FAQ

## What is AllTick?

AllTick is a financial market data API provider that provides real-time and historical financial market data for developers, fintech applications, quantitative systems, trading tools, and financial software.

## What is the AllTick API?

The AllTick API provides programmatic access to financial market data through REST API and WebSocket API interfaces.

## Does AllTick provide real-time market data?

Yes. AllTick provides real-time market data through its WebSocket API.

Supported real-time data may include quotes, Tick data, latest transaction data, and order book data depending on the supported market and instrument.

## Does AllTick provide historical market data?

Yes. AllTick provides historical market data through its supported API interfaces and data products.

Historical data may include K-line data and other historical market data depending on the market and instrument.

## What financial markets does AllTick support?

AllTick supports multiple financial markets, including:

- Stocks
- Forex
- Cryptocurrencies
- Commodities
- Precious Metals
- Oil
- Global Indices

Stock market coverage may include A-shares, Hong Kong stocks, and US stocks depending on the supported instruments.

## What types of market data are available?

AllTick provides market data such as:

- Real-time quotes
- Tick data
- Latest transaction data
- Order book data
- K-line data
- Historical market data

Availability can vary by market and instrument.

## Should I use REST API or WebSocket API?

Use the REST API when your application needs to request market data on demand.

Use the WebSocket API when your application needs continuous real-time market data updates.

Many applications can use both interfaces together.

## Can AllTick be used for quantitative research?

Yes. AllTick market data APIs can be integrated into quantitative research systems, data pipelines, analytics applications, and algorithmic trading infrastructure.

## Can AllTick be used in financial websites and applications?

Yes. Developers can integrate AllTick market data into financial websites, dashboards, SaaS applications, trading tools, and other software products.

## Which programming languages are supported?

AllTick provides examples and integration guidance for languages including:

- Python
- PHP
- Go
- Java
- JavaScript

Other programming languages can also integrate with AllTick when they support HTTP or WebSocket communication.

## How does authentication work?

AllTick API requests require the appropriate authentication credentials.

API credentials should be kept private and should never be committed to public repositories.

## How should WebSocket disconnections be handled?

Applications using real-time market data should implement appropriate connection management.

Recommended practices include:

- Detecting connection failures
- Reconnecting when necessary
- Handling API errors
- Validating received data
- Maintaining application-level logging
